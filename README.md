# SnackStack

SnackStack is a multi-agent snack ordering assistant with menu search, order
status lookup, retrieval-augmented generation, and optional voice support.

## Setup

1. Create and activate a Python 3.11+ virtual environment.
2. Install the project with `pip install -e .`.
3. Copy `.env` to `.env` and add your OpenAI API key.
4. Run `snackstack` or `python main.py`.
